# ForgeXUI

> Expressive React components with thoughtful interactions, motion, and polished UI patterns.

ForgeXUI is a growing collection of reusable React components designed for modern interfaces.

Instead of focusing only on traditional UI primitives, ForgeXUI explores components that give interfaces a stronger sense of interaction, movement, and personality while keeping the implementation clean and practical.

## ✨ What is ForgeXUI?

ForgeXUI is built around a simple idea:

**Good UI should not only look good. It should feel good to use.**

The library focuses on interactive components such as:

- Magnetic interactions
- Cursor-responsive effects
- Interactive typography
- Perspective and depth
- Playful behavioral interactions
- Subtle motion and visual feedback

Every component is designed to be reusable, customizable, and easy to integrate into a React project.

## 🧩 Components

Current components include:

- **Gradient Text**  
  Gradient typography for expressive headings and interface elements.

- **Magnetic Button**  
  A button that subtly responds to the user's cursor.

- **Spotlight Card**  
  A card with a dynamic spotlight that follows the cursor.

- **Perspective Stage**  
  A cursor-responsive 3D perspective effect for creating depth within UI compositions.

- **Runaway Button**  
  A playful button interaction that responds when a required condition has not been satisfied.

- **Guarded Action**  
  A deliberate interaction pattern for destructive actions such as deleting a project or account.

More components are being designed and added as the library evolves.

## 🚀 Tech Stack

ForgeXUI is currently built with:

- [Astro](https://astro.build/)
- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- MDX
- CSS / Web APIs

Astro powers the documentation and website, while React is used for the interactive components.
