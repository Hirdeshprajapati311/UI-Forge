# Spotlight Card

A card with a dynamic spotlight that follows the cursor.

## Installation

Copy the component into your project:

```bash
npx ui-forge add spotlight-card
```

## Usage

```tsx
import SpotlightCard from "@/components/ui/SpotlightCard";

export default function Example() {
  return (
    <SpotlightCard>
      <h2>Something interesting</h2>
      <p>Your content goes here.</p>
    </SpotlightCard>
  );
}
```

## Props

| Prop       | Type        | Default  | Description                       |
| ---------- | ----------- | -------- | --------------------------------- |
| `children` | `ReactNode` | required | Content displayed inside the card |

## About

Spotlight Card provides a subtle cursor-following light effect that adds depth to otherwise simple cards.
